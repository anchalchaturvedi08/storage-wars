New technical terms:
Header → request ke saath bheji gayi extra information.
Bearer → batata hai ki Authorization header ke andar JWT token hai.
Token → login ke baad mila authentication proof.
verify() → check karta hai token genuine aur valid hai ya nahi.
decoded → token ke andar ki information, jaise user id aur role.
req.user → hum decoded user information ko request ke andar store kar rahe hain.
next() → middleware successful hone ke baad request ko next step/controller par bhejta hai.
401 Unauthorized → user authenticated nahi hai ya token invalid hai.


3. Important new terms
...allowedRoles → Rest parameter. Multiple roles receive kar sakta hai.
* includes() → check karta hai ki given value array/list mein present hai ya nahi.
* 403 Forbidden → user logged in hai, lekin uske paas requested resource ki permission nahi hai.
Difference yaad rakho:
401 → Authentication problem
      "Tum kaun ho?"
403 → Authorization problem
      "Tumhe permission nahi hai."


New technical terms
Schema → database mein data ka structure/rules.
enum → sirf predefined values allow karta hai.
unique → duplicate category name ko prevent karta hai.
timestamps → automatically createdAt aur updatedAt create karta hai.
