My project is inspired by HistoryTV18 show storage wars, and it has three panel:

1) First hai Admin Panel, jo poore application ko manage karta hai. Admin users ko manage kar sakta hai, products ko approve kar sakta hai, auction listings manage kar sakta hai, categories aur bids ko handle kar sakta hai, aur reports bhi dekh sakta hai.

2) Second hai Seller/Bidder Panel, jahan seller pehle apna account create karke login karta hai. Uske baad wo apne products ko auction ke liye list kar sakta hai, product ki image, name, description, category aur starting bid price add karta hai, auction ki start aur end date set karta hai, aur baad mein received bids aur auction results dekh sakta hai.

3) Third hai Buyer/Customer Panel, jahan customer account create karke login karta hai. Wo available aur live auctions browse kar sakta hai, kisi product ki details dekh sakta hai, current last bid aur starting bid dekh sakta hai aur auction ke end hone tak bid laga sakta hai. Saath hi wo apni bid history, watchlist, won auctions aur orders bhi dekh sakta hai.

4) Technology ki baat karein, to frontend ke liye humne React.js use kiya hai, UI styling ke liye Tailwind CSS use kiya hai, aur different pages ke beech navigation ke liye React Router use kiya hai. Backend portion mein Node.js aur Express.js use hoga, aur data store karne ke liye MongoDB use hoga.

5) Tailwind CSS humare project ki UI styling ke liye use ho rahi hai. Iske utility classes se hum layout, spacing, colors, buttons aur responsive design easily create kar rahe hain. PostCSS ek CSS processor hai jo Tailwind CSS ko process karke final CSS generate karne mein help karta hai.
humne Tailwind use kiya hai, isiliye styling JSX me hi className ke through ki hai.

6) data.js mein maine apne application ka static/demo data centrally store kiya hai. Kyunki abhi backend aur database connect nahi kiya gaya hai, isliye frontend ko display karne ke liye categories, demo login credentials, auction listings aur products ka sample data yahan rakha hai. Different components is data ko import karke UI mein display karte hain. Future mein backend aur MongoDB connect hone ke baad ye static data database se dynamically fetch kiya ja sakta hai.

* `main.jsx` → React app ko DOM (browser ke HTML root) mein render(Render ka matlab hai React component ko browser ke DOM mein display karna) karta hai. React phir Virtual DOM ke through UI ko efficiently update karta hai.
* `App.jsx` → Application ka main component hai; ye different pages aur unki routing (`Routes/Route`) ko manage karta hai.

7) navigation ko maine separate file mein rakha hai because ye navigation ka data hai, UI component nahi. Isme admin, seller aur buyer ke menu items, unke routes aur icons define hain. Sidebar component isi data ko import karke dynamically navigation create karta hai. Isse code reusable aur maintainable rehta hai.   
navigation.js → kya-kya menu dikhana hai
Sidebar.jsx → menu ko kaise dikhana hai

8) Lucide React ek icon library hai, jiska use hum website mein ready-made SVG icons add karne ke liye kar rahe hain. Isse hume icons khud design karne ki zarurat nahi padti.

1. component:
Reusable UI components ke liye hai. Jaise Navbar, Hero, AuctionCard, Sidebar, Chatbox etc. Ek component ko multiple pages par reuse kiya ja sakta hai.

2. dashboards:
Different users ke dashboard panels ke liye hai. Isme Admin, Seller/Bidder aur Customer/Buyer ke dashboard aur unke related pages hain.

3. data:
Static/demo data store karne ke liye hai. Jaise categories, auction products, demo login credentials etc. data folder currently reserved for static or demo data, but in the current frontend version demoData.js is not being used because the file is empty. Later, when we connect the backend, the static data will be replaced by dynamic data coming from the database.

4. pages:
Website ke main pages ke liye hai. Jaise Home, About, Contact, Auctions, Categories, Login aur Auction Detail pages. Ye pages different components ko combine karke complete screen banate hain.

5. utils:
utils mein helper/utility functions rakhe jaate hain jo baar-baar different files mein use hote hain. Jaise tumhare project mein formatters.js amount/currency ko proper format mein dikhane ke kaam aa raha hai.

IMP: React + Node + Express + MongoDB + JWT + bcrypt + Nodemailer + Cloudinary + Payment Gateway + REST API + Role-based Authorization
